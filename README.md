# Sistema de Personajes para Videojuego de Rol 🎮

Un sistema orientado a objetos para gestionar personajes en un videojuego de rol, implementando herencia, polimorfismo e interfaces.

## Características Principales 🛠️
- **Jerarquía de clases**: 
  - Clase abstracta `Personaje`
  - Subclases: `Guerrero`, `Mago`, `Arquero`, `Hechicero`, `Asesino`
- **Sistema de combate**:
  - Batallas por turnos interactivas
  - Daño variable según tipo de ataque
  - Sistema de defensa y curación
- **Interfaz de usuario**:
  - Menú principal interactivo
  - Selección libre de personajes
  - Visualización de habilidades
- **Personajes predefinidos** con estadísticas balanceadas

## Tecnologías Utilizadas 💻
- **Java 8+**
- **Programación Orientada a Objetos** (POO)
- **Patrón MVC** (Modelo-Vista-Controlador)
- **Maven** (Gestión de dependencias)
